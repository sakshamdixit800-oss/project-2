# Project 2 — HEDWIG Translator

A lightweight browser translator UI. It sends text to the [MyMemory Translation API](https://mymemory.translated.net/doc/spec.php) and displays the translated response.

## Run

Open `index.html` in a browser. For best results, serve the folder with any local static server so browser permissions work consistently.

## Features

- Source and target language selection
- Language swapping
- Translation through a live API request
- Copy translation to clipboard
- Text-to-speech using the browser Speech Synthesis API
- Character count, clear button, loading state, and keyboard shortcut (`Cmd/Ctrl + Enter`)
